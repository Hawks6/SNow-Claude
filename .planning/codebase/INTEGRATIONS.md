# External Integrations

This document details the external systems and services that SNow-Claude interacts with or targets.

## Primary Targets
- **ServiceNow Instances**: Target for deployment of generated code.
- **ServiceNow API Frameworks**: 
    - REST API Explorer
    - Scripted REST APIs
    - Flow Designer & IntegrationHub
    - **Process Automation Designer (PAD) & Playbook Experience**


## LLM Providers
- **Anthropic (Claude)**: The primary engine for processing meta-prompts and generating ServiceNow artifacts.

## Infrastructure & Tools
- **Git/GitHub**: For version control of the SNow-Claude knowledge base.
- **Claude Projects**: A specific integration point where the markdown files are uploaded as project knowledge.
